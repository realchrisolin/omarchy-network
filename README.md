# realchrisolin.network

Omarchy bar Network widget, cloned from `omarchy.network`.

Plugin id: `realchrisolin.network`  
Live path: `~/.config/omarchy/plugins/realchrisolin.network`

Keeps `ipcTarget: omarchy.network`. Helper scripts in `bin/` take `--iface`
so the panel can pin the selected adapter instead of the packaged first-device
default.
